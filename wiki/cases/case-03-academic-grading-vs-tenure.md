# 案例 3：學術生存戰 —— 資深教授違規放水評分與 Tenure 威脅

## 1. 情境快照（Scenario Snapshot）
> [!NOTE] 新人視角情境
> 林博士（31 歲）剛取得頂尖名校博士學位，歷經重重遴選獲得國立大學助理教授職位。根據學校聘約，他必須在六年內通過嚴格的評鑑與同儕審查，否則將依「限期升等未過（Up-or-out）」規定被不續聘，直接斷送學術生涯。
> 
> 在第一學年期末，林博士與系上德高望重、擔任教評會召集人的資深講座教授 A 教授合開一門大三必修核心課程。在期末評分會議上，林博士驚愕地發現：幾位整學期曠課多次、期末考卷幾乎空白且抄襲嚴重的學生，在 A 教授的成績冊上竟然全數拿到 85 分以上的高分（A 等級）。
> 
> 林博士向 A 教授提出疑問，A 教授私下拍拍他的肩膀，微笑中帶著濃厚的威脅意味說：「林老師，做人要圓融。這幾位學生的家長是我們學院新大樓的最大捐款人，還有幾位是校長重視的重點企業二代。系上需要資源，大家各取所需。對了，聽說你明年要提第一次三年續聘與 Tenure 預審？教評會大家都很看重你的『團隊合作精神與大局觀』，我想你應該很清楚系上的期待吧？」
> 
> 林博士陷入無比痛苦的深淵：向系主任（Department Head）或學術誠信委員會舉報 A 教授的違規放水，A 教授極可能動用強大的學閥人脈在審查會上將其封殺，令其多年的學術苦讀付諸流水；但若默不作聲，自己便背叛了身為教師的公正誓言，並嚴重傷害了其他苦讀學生的受教權。

## 2. 利害關係人與權力不對等分析（Stakeholder & Power Matrix）

| 利害關係人 | 權力地位 | 核心訴求 / 期待利益 | 承擔的風險與受損可能 |
| :--- | :--- | :--- | :--- |
| **林博士（助理教授）** | 極弱（聘期未定、生死大權在他人手中） | 保住飯碗、順利取得 Tenure、維護教學良心 | 被解聘、學術圈名聲被封殺、良知折磨 |
| **A 教授（資深學閥/教評召集人）** | 極強（握有資源、掌握教評會票數） | 討好校長與捐款金主、穩固個人在校權力 | 評分舞弊曝光面臨學術調查與名譽受損 |
| **刻苦修課的其他多數學生** | 弱（資訊封閉、無權力） | 公平競爭、客觀受評、文憑信譽 | 成績被稀釋、遭受不公正待遇、教育幻滅 |
| **特權學生與捐款人家長** | 強（擁有財富與贊助籌碼） | 輕鬆獲取高分文憑、維持光鮮履歷 | 作弊護航被踢爆後面臨學籍處分 |
| **大學機構與學術社群** | 體系名譽受託者 | 維持學術公信力、學位授予威信 | 學位文憑貶值為商品、學術腐敗醜聞 |

## 3. 四大學派倫理視角交鋒（Theories in Action）

| 倫理學派 | 核心評判考量 | 對此情境的道德判斷與行動指引 | 理論局限性與反思 |
| :--- | :--- | :--- | :--- |
| **康德義務論**<br>*(Kantian)* | • 人非工具公式<br>• 定言令式嚴禁背棄職責 | • **絕對禁止妥協**：將公平評分職責拿去換取個人 Tenure，是把學生當作保全個人職位的工具；也是把學位當作換取大樓贊助的商品，徹底踐踏了人性的尊嚴。<br>• **行動指引**：林博士出於維護道德律的純粹義務，必須拒絕同謀，即使被解聘亦在所不惜。 | 要求一個年輕學者為了崇高理想承受學術死亡的代價，現實中極端殘酷且罕有人能承受。 |
| **羅斯直覺義務論**<br>*(Ross's Deontology)* | • 顯見義務衝突：<br>  - 正義（Justice/公平評分）<br>  - 自我提升/自我保護（Self-preservation）<br>  - 不傷害（Non-maleficence/對其他學生之傷害） | • **分析**：對學術正義的義務與對一般學生不傷害的義務，高於對前輩盲目感恩或個人職涯的自私考量。<br>• **行動指引**：承認林博士自我保全的顯見義務是合法的，因此不建議無謀地公開正面衝撞；而是尋求**「實質捍衛正義、同時降低自我傷害」**的智慧路徑（如秘密備份卷證、向校外獨立誠信機構或外部匿名舉報）。 | 如何在正義與自我保全之間找到平衡點，需要極高的政治智慧與策略。 |
| **道德相對主義**<br>*(Moral Relativism)* | • 學閥潛規則與生態：<br>「象牙塔本來就有政治學」 | • 指出「大學本就是社會縮影，靠金主維持運轉是私下約定俗成的生存之道」。相對主義會勸林博士「先拿到 Tenure 活下來，以後當了大老再來改變制度」。<br>• **批判**：當你妥協第一次，你的道德底線就已徹底潰決；等拿到 Tenure 時，往往自己也成為了下一個 A 教授。 | 容易成為年輕學者對體制屈服、放棄專業原則的心靈麻醉劑。 |
| **道德絕對主義**<br>*(Moral Absolutism)* | • 學術評價客觀真理：<br>評分舞弊客觀本質為不可赦之偽造 | • 學位的本質是能力的證明。刻意在成績冊上給予不實成績，等同於公文書造假與背叛委託。這種行為在客觀上沒有任何藉口與妥協空間。 | 無法提供在強權碾壓下弱勢新人的防禦指引。 |

## 4. 專業人士基本特質與義務檢核（Professionalism Checklist）

- [x] **專業訓練與實習（[[qualifications]]）**：大學教授受過最嚴格的博士訓練，理應捍衛客觀真理與科學評量標準。
- [x] **專業決策自主權（[[autonomy]]）**：教師在課堂與成績評定上享有《憲法》保障的講學自由與專業自主，嚴禁受外部金錢或行政威脅干涉。
- [x] **受託責任與公眾信任（[[fiduciary-duty]]）**：大學文憑是向社會公眾出具的信用背書。評分造假直接摧毀了社會對大學專業的公眾信託。
- [x] **學生權益知情與公平（[[informed-consent]]）**：學生有權要求在統一透明的評量尺規下接受公正考核。

## 5. 倫理決策路徑與行動建議

1. **第一防線：堅持職權分工，絕不親自簽核不實成績**
   * 對合開課程的自己負責評分之區塊（如期末考或個人作業），嚴格依規準給分。
   * 明確告知 A 教授：「報告老師，我評估的這部分有詳實的扣分扣考依據，我只能依真實考卷成績送交教務處。若老師個人要在總成績中依授課教師自主權進行額外加分調整，請老師以您的權責送出。」（確保自己手上不沾染偽造罪證）。
2. **第二防線：完整留存原始卷證與通訊紀錄（Data Preservation）**
   * 秘密將學生的原始空白考卷、抄襲比對系統報告、雙方的 email 通訊或面談日記進行離線客觀備份（以備日後遭受不當考績評議時向申訴委員會舉證防衛）。
3. **第三防線：串聯外部與體制外力量（Whistleblowing Strategy）**
   * 不要在毫無準備下單挑權威。在 Tenure 評審過程中，若 A 教授確有打擊報復行為，向校長、教務長、獨立學術誠信委員會或教育部高等教育申訴評議委員會提出具名檢舉與行政訴願，以法治防堵學閥私刑。

## 6. 簡報提煉卡片（Slide-Ready Presentation Card）

> [!TIP] 投影片核心金句（Slide Takeaway）
> **「拿文憑換大樓的代價——在權力巨峰下的學術良知」**
> * **核心兩難**：當大老告訴你「想活下來就要放水」，你是否要把學位變質為逢迎的籌碼？
> * **思辨金句**：如果你選擇先同流合汙換取生存，當你有一天爬上權力頂點時，你早已變成你當初最痛恨的那個大老。
> * **哲學指引**：康德警告我們絕不可將學生與學位當作換取職位的工具；羅斯提醒我們，對學術正義的堅持是不能被個人前途交換的實際義務。
