# 案例 2：職場微腐敗 —— 同事私帶公司用品「反正大家都拿」

## 1. 情境快照（Scenario Snapshot）
> [!NOTE] 新人視角情境
> 阿豪（22 歲）剛自商學院畢業，通過激烈的面試進入一家知名跨國物流公司的行銷與行政部門擔任企劃專員。
> 
> 入職第三週，週五下班前，同組同梯次進來、但比他年長兩歲的前輩兼同仁阿凱，在茶水間與庫房整理盤點時，打開背包，將兩大盒進口高級雷射列印專用紙、一整盒昂貴的品牌鋼珠筆，甚至是一支全新未拆封的高解析度簡報雷射筆放進私人物品袋中。
> 
> 阿凱看到阿豪驚訝的表情，神態自若地笑著塞了一支高級簡報筆給阿豪說：「拿去用啦！這本來就是部門採購預算多報的剩餘物資。公司每個月營收幾億，根本沒人在乎這幾千塊的文具。我每個月都拿，大家私底下都這樣做，主管也都睜一隻眼閉一隻眼。你剛來別太拘謹，這算員工福利的一種，不拿白不拿，只要你不說、我不說，沒人會知道！」
> 
> 阿豪手握著那支筆，內心無比糾結：收下，自己成了共犯；拒絕，可能立刻被阿凱視為異類並在組內遭到孤立；若向主管或政風舉報，阿凱可能會被開除，而自己將背負「抓耙子」的惡名。

## 2. 利害關係人與權力不對等分析（Stakeholder & Power Matrix）

| 利害關係人 | 權力地位 | 核心訴求 / 期待利益 | 承擔的風險與受損可能 |
| :--- | :--- | :--- | :--- |
| **阿豪（剛畢業新人）** | 弱（新進員工、極需人際認同） | 融入團隊、順利通過試用期、維持內心清白 | 被孤立排擠、被構陷為共犯、誠信受損 |
| **阿凱（違規同事）** | 中（組內老鳥、熟悉潛規則） | 獲取小額物質利益、拉新人下水共同掩護 | 依勞基法與刑法侵占罪受懲處甚至解僱 |
| **直屬部門主管** | 強（行政管理權、考核權） | 專案順利推進、部門預算消耗合理、不生事 | 涉嫌督導不周、面臨內控審計查核連帶處分 |
| **公司股東與全體員工** | 系統受害者 | 內部資產安全、誠信企業文化、合規治理 | 破窗效應擴大、成本虛增、組織道德滑坡 |

## 3. 四大學派倫理視角交鋒（Theories in Action）

| 倫理學派 | 核心評判考量 | 對此情境的道德判斷與行動指引 | 理論局限性與反思 |
| :--- | :--- | :--- | :--- |
| **康德義務論**<br>*(Kantian)* | • 普遍化原則檢驗<br>• 定言令式絕對禁止竊盜 | • **普遍化檢驗**：若每位員工都意願「將雇主未授權的資產私自帶回家」，那麼「財產所有權」與「受雇信託」將在概念上崩塌。偷竊無論價值大小，皆不能被普遍化。<br>• **批判**：阿豪收下或同流合汙在道德上絕對有罪；阿豪必須堅定拒絕。 | 康德強調理性原則，但未能替新人解決在被孤立時的情緒壓力與生存策略。 |
| **羅斯直覺義務論**<br>*(Ross's Deontology)* | • 顯見義務衝突：<br>  - 忠誠（對公司的契約誠實）<br>  - 仁慈/和諧（對同儕的和睦相處）<br>  - 正義（不當獲利之糾正） | • **分析**：對公司的「忠誠義務（遵守合約不侵占公物）」與「正義義務（公平分配公司資源）」明顯壓倒「與同儕表面和睦相處」的次要義務。<br>• **指引**：絕不可同流合汙（違反正義與誠實）。關於是否立即檢舉，羅斯允許評估「比例原則」：先透過溝通劃清界線，避免盲目行使破壞性報復。 | 如何精確拿捏「私下拒絕」與「正式向公司舉報」的門檻，仰賴道德實踐智慧。 |
| **道德相對主義**<br>*(Moral Relativism)* | • 職場組織次文化：<br>「大家都這樣＝在我們這算正常」 | • 完美展示了相對主義的邏輯圈套：「大家都在拿」成為阿凱脫罪與拉攏的藉口。在阿凱的小圈子裡，這被定義為「無害小確幸」。<br>• **批判**：這正是典型的**破窗效應（Broken Windows Theory）**，將違法行為文化化，是組織腐敗的根源。 | 若採信相對主義，新人將逐步被溫水煮青蛙，從偷拿文具走向更大的職務舞弊。 |
| **道德絕對主義**<br>*(Moral Absolutism)* | • 道德底線客觀存在：<br>竊盜即是竊盜，不因物品價值而變性 | • 「不告而取謂之偷」。無論價值是一支原子筆還是一百萬現金，侵占行為的道德本質完全一樣。任何藉由「預算剩餘」、「大家都拿」的辯解皆是自欺欺人。 | 對剛進公司的新人要求過於嚴苛，容易讓新人產生無力感或過早心灰意冷。 |

## 4. 專業人士基本特質與義務檢核（Professionalism Checklist）

- [x] **專業訓練與品德誠信（[[qualifications]]）**：受過高等教育的專業人員，應具備基本的法律常識與職業操守認知，不得裝作無知。
- [x] **專業自主權（[[autonomy]]）**：阿豪有權力不受同儕「大家都這樣」的綁架，自主決定維護個人的職業操守。
- [x] **受託責任（[[fiduciary-duty]]）**：受雇者領取薪資，對公司資產負有受託妥善保管的義務，嚴禁監守自盜。

## 5. 倫理決策路徑與行動建議

1. **第一步：立即、禮貌但堅決地拒絕（劃清個人防線）**
   * 把筆放回桌上：「阿凱，謝謝你的好意，但我家裡筆夠用，而且我習慣公私分開，拿公物我心裡會不安，這個我就不拿了。」
   * **關鍵心法**：不直接進行道德說教或威脅檢舉，但明確建立個人邊界，讓對方知道自己不是同道中人。
2. **第二步：自我保護與留存證據**
   * 確保自己在庫房簽收與盤點表格上，只為自己親手經辦與留在公司的物資簽字，**絕不在任何虛假的報銷單或盤點單上代簽或共同背書**。
3. **第三步：衡量檢舉與介入時機（Whistleblowing Decision）**
   * 若阿凱僅是個人偶發拿取筆記本，阿豪守住底線不參與；
   * 若阿凱涉嫌組織性、常態性搬移高價值設備（如電腦螢幕、轉售公司耗材），這已構成刑事侵占與公司重大資產流失。此時應透過公司匿名合規信箱（Compliance Hotline）或內部審計通報，恪盡專業受託責任。

> * **核心兩難**：「大家都拿，就你不拿，你是不是想當抓耙子？」——面對辦公室微腐敗與同儕威脅。
> * **思辨金句**：廉潔不是由你貪了多少錢來定義，而是由你拒絕妥協的那一塊錢開始確立。
