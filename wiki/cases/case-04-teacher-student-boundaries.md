# 案例 4：校園權力界線 —— 教授與學生的社交界線與雙重關係

## 1. 情境快照（Scenario Snapshot）
> [!NOTE] 新人視角情境
> 曉萱（24 歲）剛自大學頂尖科系畢業，進入研究所攻讀碩士學位。指導教授 B 教授（45 歲）是國際學術知名學者，掌握著實驗室龐大的研究經費、國際研討會推薦名額以及畢業口試委員會的組成人選。
> 
> 在入學半年後，B 教授開始在深夜傳訊關心曉萱的私人感情生活，頻繁以「討論國際前沿論文」為由，單獨約曉萱至高級餐廳或私人酒吧，並在言談中反覆提及「只要跟著我，未來的博士推薦信與海外名校教職包在我身上」。不久後，B 教授更進一步在密閉研究室內有過度的肢體搭肩與曖昧示好。
> 
> 曉萱感到極度不適與焦慮，但深知 B 教授掌握自己能否順利畢業、是否能拿到獎學金的絕對生殺大權。當她向同實驗室學姐旁敲側擊求助時，學姐卻嘆氣說：「老師對長得好看的學妹一向這樣，只要順著他、偶爾陪他喝喝酒吃個飯，畢業口試輕輕鬆鬆就過了；如果跟他翻臉，以前有學長被卡了四年都沒拿到學位最後憂鬱休學。」曉萱身陷窒息般的雙重關係陷阱中。

---

## 2. 利害關係人與權力不對等分析（Stakeholder & Power Matrix）

| 利害關係人 | 權力地位 | 核心訴求 / 期待利益 | 承擔的風險與受損可能 |
| :--- | :--- | :--- | :--- |
| **曉萱（研究生）** | 極弱（完全依附指導教授） | 獲取專業指導、順利畢業、身心不受騷擾 | 學位被卡死、身心受創、遭受流言蜚語 |
| **B 教授（指導教授）** | 極強（握有資源、評分、口試大權） | 滿足私人情感/慾望、維持權威與學術聲望 | 觸犯性別平等法、面臨停聘或解聘懲處 |
| **同實驗室其他同儕** | 弱（身處連帶受波及體系） | 實驗室和諧、資源分配正常 | 資源被偏心分配、處於有毒工作環境 |
| **學術機構與教育體制** | 體系名譽承擔者 | 維護安全平等的受教環境、防杜權力霸凌 | 爆發 Metoo 醜聞、面臨國家性平調查 |

## 3. 四大學派倫理視角交鋒（Theories in Action）

| 倫理學派 | 核心評判考量 | 對此情境的道德判斷與行動指引 | 理論局限性與反思 |
| :--- | :--- | :--- | :--- |
| **康德義務論**<br>*(Kantian)* | • 人非工具公式<br>• 定言令式嚴禁濫權利用 | • **嚴重物化與支配**：B 教授將學生的學術熱情、信任與畢業前途當成滿足個人情感或慾望的工具，完全違背「人是目的本身」的絕對道德命令。<br>• **批判**：師生之間存在嚴重的制度性權力傾斜，在此種依附關係下，根本不可能存在真正的「自由自主意願」。 | 未給予弱勢學生在孤立無援時的具體反擊工具。 |
| **羅斯直覺義務論**<br>*(Ross's Deontology)* | • 顯見義務衝突：<br>  - 不傷害（Non-maleficence）<br>  - 忠誠（Fidelity/受託責任）<br>  - 自我保護（Self-preservation） | • **分析**：B 教授徹底違反了身為教師的「忠誠/信託義務」與「不傷害義務」。<br>• **行動指引**：對曉萱而言，保護自身身心安全與人格尊嚴是當前的實際義務。學生的退讓並不能換取真正的仁慈，反而會招致更深的持續傷害。 | 權衡過程中需要評估轉換指導教授或申訴的現實制度阻力。 |
| **道德相對主義**<br>*(Moral Relativism)* | • 實驗室封閉文化：<br>「學界本來就有這種事」 | • 揭露了閉門實驗室內的有毒默契：「順從換學位」被合理化為一種利益交換的潛規則。<br>• **批判**：這種相對主義抹殺了學術研究的尊嚴，將指導關係墮落為封建依附與剝削關係。 | 若順從此文化，受害者將被迫內化創傷並在日後複製給下一代學生。 |
| **道德絕對主義**<br>*(Moral Absolutism)* | • 道德底線客觀不可跨越：<br>利用權力不對等侵犯界線本質為惡 | • 專業指導關係中的「雙重關係（Dual Relationships）」與性騷擾，在客觀本質上屬於不可赦免的權力濫用。任何藉由「彼此自願」、「真愛」為名的辯解，在具有直接利益審查關係下皆屬偽善。 | 過於抽象，若直接硬碰硬缺乏防衛技巧，學生往往先受重創。 |

## 4. 專業人士基本特質與義務檢核（Professionalism Checklist）

- [x] **專業資格與執業操守（[[qualifications]]）**：教師承載著國家與社會賦予的教育指導特許權，負有維持純粹學術指導環境的最高標準操守。
- [x] **受託責任（[[fiduciary-duty]]）**：指導教授是學生的受託導師（Mentor），負有保護學生學術探索的信託責任，嚴禁將受託地位變質為個人情感提款機。
- [x] **真誠知情同意（[[informed-consent]]）**：在權力高度不對等（Power Imbalance）的架構下，**根本無法形成真正法律與倫理意義上的「知情同意」**，任何示好本質上皆帶有隱性強制力。
- [x] **自主權保護（[[autonomy]]）**：學生的研究自主權與人身自主權必須受到完整維護，不得遭受任何學術人質綁架。

## 5. 倫理決策路徑與行動建議

1. **第一步：建立嚴密的「專業邊界（Professional Boundaries）」**
   * **溝通管道公事化**：嚴格使用學校官方信箱（.edu）或公開通訊軟體對話，婉拒深夜非公務之私訊。
   * **會面地點公開化**：堅持在白天、學校開放研究室或有其他人在場的研究空間討論論文，堅決拒絕私人酒吧或密閉非公務邀約。
2. **第二步：客觀證據留存（Documentation）**
   * 詳實截圖保存所有帶有曖昧、暗示利益交換、深夜騷擾之通訊對話與錄音，並備份於校外私人雲端。
3. **第三步：啟動校園制度防禦機制**
   * 聯繫學校「性別平等教育委員會（性平會）」尋求保密諮詢。
   * 依據學位法規申請**「更換指導教授」**（在保留研究進度與學分前提下轉換至誠信良好的導師門下），切斷權力依附鏈條。

## 6. 簡報提煉卡片（Slide-Ready Presentation Card）

> [!TIP] 投影片核心金句（Slide Takeaway）
> **「在不對等的權力下，沒有真正的『自願』——捍衛學術與身心的神聖界線」**
> * **核心兩難**：當導師用「學位前途」包裹「情感索求」，學生該如何掙脫制度性的枷鎖？
> * **思辨金句**：教育的本質是賦能（Empowerment），而非將學生的前途變相質押為個人的禁臠。
> * **哲學指引**：康德告誡我們：權威者若將學生的身體與心靈當成私慾的工具，便徹底喪失了為人師表的道德合法性。
