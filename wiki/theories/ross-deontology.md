# 羅斯直覺義務論（Ross's Intuitionist Deontology）

## 1. 核心思想概述與學理背景
蘇格蘭哲學家威廉·大衛·羅斯爵士（Sir W. D. Ross）在 1930 年出版的經典《正當與善》（*The Right and the Good*）中，建立了**「多元直覺義務論（Pluralistic Intuitionist Deontology）」**。他同時批判並修正了古典哲學的兩大極端：
1. **修正康德的單一絕對主義**：康德堅持道德法則絕對無例外（如絕不說謊）。羅斯以**常識道德（Common-Sense Morality）**指出，當「說真話」會導致無辜者被屠殺時，救人顯然是更優先的實際義務。
2. **反擊功利主義的扁平後果論**：功利主義將所有道德簡化為追求未來的總量利益。羅斯提出了兩大劃時代批判：
   * **回溯性義務（Backward-Looking Duties）**：人類多數神聖義務源於「過去的事實」（如因過去許諾而有忠實義務、因過去傷害而有補償義務、因過去受助而有感恩義務），而非未來能賺多少好處。
   * **義務的高度個人特質（The Highly Personal Character of Duty）**：道德不是非個人的總體算計，而是根植於「受諾人與承諾人、病患與醫生、學生與教師」之間具體而神聖的身分承諾。

---

## 2. 兩大核心範疇：顯見義務 vs. 實際義務

羅斯最革命性的貢獻，在於精確區分了道德特質的兩種狀態：

* **顯見義務（Prima Facie Duties / Conditional Duties）**：
  * 在「其他條件相同」的前提下，行動本身具有的客觀道德傾向與約束力。
  * 它並非虛假的幻象，具有持續客觀的道德重量。即使在特定情境下被另一項更高義務壓倒，它依然存在，並形成**「道德殘留（Moral Residue）」**（要求我們事後補償、致歉或說明）。
* **實際義務（Actual Duty / Duty Proper）**：
  * 當多項顯見義務在具體情境中互相衝突時，經由深思熟慮與道德直覺權衡後，**最終在當下這個具體時空中，行動者必須付諸實踐的唯一決定性義務**。

## 3. 羅斯的七大顯見義務（Seven Prima Facie Duties）

| 義務群組 | 具體顯見義務 | 道德立論基礎與意涵 | 專業職場實踐體現 |
| :--- | :--- | :--- | :--- |
| **源於自己過去行動** | **1. 忠誠（Fidelity）** | 遵守明確與默示承諾、誠實守信、不背叛信託 | 遵守專業契約、如實向委託人揭露真相、不隱瞞漏洞 |
|  | **2. 補償（Reparation）** | 為自己過去做錯的事向受害者進行補償糾正 | 發現醫療或工程疏失時立即承認並補救，主動賠償損失 |
| **源於他人過去行動** | **3. 感恩（Gratitude）** | 感念他人曾給予的無私幫助與善意好處 | 感謝資深前輩帶領、感念公司培養（但不能凌駕於更高義務之上） |
| **正義與分配公平** | **4. 正義（Justice）** | 依照功績與德行公平分配利益與負擔，防止特權 | 依客觀標準給學生評分、反對徇私護航金主、落實平權 |
| **改善世界狀態** | **5. 仁慈/行善（Beneficence）** | 積極增進他人的福祉、德行、智慧或快樂 | 積極為病患著想、主動協助新人、優化系統體驗 |
|  | **6. 自我提升（Self-Improvement）** | 提升自己的道德水平、知識與專業技能 | 持續在職進修、維持執照專業水準、自省道德偏見 |
| **不可傷害（最優先）** | **7. 不傷害他人（Non-Maleficence）** | **最優先之義務**：絕不主動對他人施加實質傷害 | 絕不因趕工交付有致命隱患之系統、嚴禁傷害病患生命 |

> [!IMPORTANT] 羅斯的黃金排序法則
> 羅斯在《正當與善》中明確指出：**「不傷害他人（Non-maleficence）」的義務通常重於「行善（Beneficence）」與「感恩/忠誠（Gratitude）」**。
> 當保護同僚的人情人脈與防止公眾受到實質傷害衝突時，不傷害原則具有壓倒性的決定優先權。

## 4. 道德知識論：直覺主義與實踐智慧（Phronesis）

面對「我們如何知道義務是什麼？」的難題，羅斯提出：
1. **顯見義務原則具有「自明性（Self-Evidence）」**：
   * 猶如數學幾何公理，一個心智成熟且理性反省的人，能夠直覺地把握「不可無故害人」、「應當守諾」的客觀真理性，無需功利計算的繁瑣證明。
2. **實際義務判定「不具自明性」，仰賴「實踐智慧（Phronesis）」**：
   * 在具體衝突中判定哪一項義務晉升為「實際義務」，**不存在機械公式或數學演算法**。
   * 行動者必須運用亞里斯多德式的「實踐智慧（Phronesis）」、道德敏感度與對事實全貌的審查，做出**「深思熟慮的意見（Considered Opinion）」**。雖然我們無法擁有數學般的絕對確定性，但這正是專業倫理決策的真實風貌。

## 5. 羅斯的四大內在價值（Theory of Intrinsic Goodness）
羅斯主張價值多元論，認為世上有四種自身即善的事物：
1. **德行（Virtue）**：追求正當的道德意志。
2. **知識與正確認知（Knowledge）**：對真理的理解。
3. **快樂（Pleasure）**：正當、無辜的幸福與喜悅。
4. **正義相配（The allocation of pleasure to virtue）**：善有善報、幸福與德行相配的公平狀態。

## 6. 面對職場道德兩難時的權衡步驟（決策架構）
1. **列出衝突清單**：辨識當下打架的是哪幾項顯見義務（例如：對主管的忠誠 vs. 對公眾的不傷害；對同儕的感恩 vs. 對學術客觀的正義）。
2. **評估危害緊迫度**：如果放棄某一義務，會造成的實質物理、心理或制度傷害有多大？
3. **直覺理性權衡**：牢記「不傷害原則具有最高加權重」，在情境全貌下決定當前的「實際義務」。
4. **補償道德殘留**：在履行實際義務的同時，對被暫時擱置的次要義務給予誠懇說明與適當補救。
