# rawpapers 教學與學術文獻專區 (Immutable Raw Sources)

本資料夾專門存放由使用者提供或從外部連結下載的 **PDF 教學教材、學術論文、倫理案例研析講義及相關補充文獻**。

---

## 檔案管理與命名規範
1. **原始 PDF 檔案**：
   * 檔名格式：`YYYY-MM-DD-主題名稱.pdf`（或保留原始來源清晰英中文檔名）。
   * 屬性：**唯讀不可變（Immutable）**，保留最原始的文獻檔案。
2. **對應繁體中文擷取檔（自動生成）**：
   * 檔名格式：`YYYY-MM-DD-主題名稱_zh.md`。
   * 由 Agent 讀取 PDF 後，自動翻譯為符合臺灣專業倫理用語習慣的繁體中文，並萃取四大哲學學派、專業特質檢核、案例兩難與決策模型的精華內容。
