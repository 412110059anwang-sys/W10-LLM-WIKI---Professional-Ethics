## 📚 知識庫架構（Three-Layer Architecture）

1. **`slides/`**：HTML 互動講義與展示入口。
2. **`assets/`**：圖文講義視覺素材（いらすとや插圖）。
3. **`wiki/`**：由 Agent 維護之長青結構化知識庫（含四大哲學學派、專業人士特質、畢業生兩難案例與決策模型）。
4. **`rawpapers/` & `raw/`**：PDF 論文、教學講義與權威文獻繁中萃取報告。
5. **`Agents.md`**：系統治理手冊與作業規範。
